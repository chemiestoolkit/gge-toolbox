🎰 Gacha Rankings

Live leaderboards for the gacha events — Halloween Banquet, King's Banquet, the Enchanted Snowglobe and the rest — read straight off the game servers. Save your name to keep your own rank in view; the page refreshes itself while it's open.

About the data: the game's own gacha highscore lists (highscore types 80–88 — the Halloween Banquet is 86), read live via danadum's empire-api, the same source as the Player & Alliance Rankings. In the game itself the gacha window only shows your own rank; this is the whole list. A gacha that isn't running on a server shows no entries.
